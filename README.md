# 🛒 CampusBuyAI
### AI-Powered Agentic Commerce Platform for Students

> Built for the **Prava Agentic Commerce Hackathon 2026**

---

# 📌 Overview

CampusBuyAI is an AI-powered agentic commerce platform designed specifically for university students. Instead of manually searching across multiple shopping websites, students simply describe what they need in natural language.

The AI agent understands the request, compares available options, recommends the best product, and enables a seamless purchase workflow through **Prava's Agentic Commerce infrastructure**.

The project demonstrates how autonomous AI agents can safely assist users throughout the complete commerce journey—from intent to transaction.

---

# 🚀 Problem Statement

Students face several common purchasing challenges:

- Spending excessive time comparing products.
- Difficulty identifying the best value for money.
- Information overload across multiple shopping platforms.
- No personalized assistant dedicated to educational purchasing.
- Complicated checkout experiences.

CampusBuyAI solves these problems by acting as an intelligent shopping assistant capable of understanding user intent and simplifying purchasing decisions.

---

# 💡 Solution

CampusBuyAI combines Artificial Intelligence with Agentic Commerce to automate the shopping process.

The AI agent:

- Understands user requirements
- Suggests relevant products
- Provides intelligent recommendations
- Helps users make informed purchasing decisions
- Enables secure commerce workflows using Prava

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/CampusBuyAI.git
```

Go into the project

```bash
cd CampusBuyAI
```

Install dependencies

```bash
npm install
```

Install backend dependencies

```bash
cd backend
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend directory.

Example:

```env
OPENAI_API_KEY=your_openai_api_key
```

**Important**

Do not upload your `.env` file to GitHub.

---

# ▶ Running the Project

Start backend

```bash
node server.js
```

Open frontend

```
frontend/index.html
```

or

```
http://localhost:3000
```

---

# 🔄 Workflow

1. User enters shopping query.
2. Frontend sends request to backend.
3. Backend communicates with OpenAI.
4. AI processes the request.
5. Product recommendation is generated.
6. Commerce flow is initiated using Prava.
7. User completes purchase.

---

# 🔐 Security

- API Keys stored using environment variables.
- `.env` excluded from GitHub.
- No sensitive credentials exposed.
- Secure server-side API communication.
